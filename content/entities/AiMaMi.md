# AiMaMi

**AiMaMi** 是 OpenAI Codex 的原生桌面伴侣，**不是 fork 或套壳**，而是在 Codex 之上提供官方客户端不具备的能力。核心理念：把 Codex 从单账号单模型工具变成多账号、多模型、多会话的企业级工作台。

**GitHub**: [borawong/AiMaMi](https://github.com/borawong/AiMaMi) · ★506 · Apache 2.0

## 核心亮点

- **多账号轮换** — 管理无限量 Codex 账号，实时监控额度，额度耗尽自动切换
- **会话树管理** — 以项目分组的树形结构可视化所有 Codex 线程，支持批量删除与丢失线程恢复
- **中转模型注入** — 在 Codex 模型菜单中注入第三方模型（GPT / Claude / DeepSeek / 本地模型）
- **MCP & Skills** — MCP 服务器与技能包的完整生命周期管理
- **自定义指令** — 模板化指令注入，支持预览、应用、回滚和历史追踪

## 账号管理

```
无限量 Codex 账号
    ↓
实时额度监控（双窗口：5小时 + 周度）
    ↓
自动轮换（双阈值触发 + 智能候选选择）
    ↓
弹出通知（确认后切换并重启 Codex）
```

| 功能 | 说明 |
|------|------|
| 一键添加/切换/删除 | 跨邮箱、别名、账户名、工作区多字段搜索 |
| 额度监控 | 百分比进度条 + 重置倒计时，可配置刷新间隔（30秒~5分钟）|
| 令牌健康 | 行内状态徽章：缺少 refresh token / refresh 被拒 / 临时故障 |
| 自动轮换 | 双阈值独立设置，智能选出额度最充裕账号 |
| 备份恢复 | 导出为可移植文件，导入时预览新增/覆盖/跳过 |
| API 代理 | 直连或自定义代理 URL，支持系统代理检测 |

## 线程管理

Codex 官方客户端从未暴露的能力：

| 功能 | 说明 |
|------|------|
| 线程树视图 | 按项目分组，父子线程折叠展开，展示名称/子线程数/文件大小/状态徽章 |
| 批量操作 | 多选单条/整分支/整项目，批量删除后自动刷新 |
| 丢失线程恢复 | 扫描消失的线程，批量恢复（需先关闭 Codex）|
| 孤儿检测 | 父线程不存在的线程被标记统计 |
| 会话分析 | 总线程数/存储大小/活跃天数/日均线程数 + 趋势图表 |

## 智能路由

在 Codex 模型菜单中注入第三方模型，**与官方模型共存**：

```
无限量 Provider
    ↓
API Key 安全存储（系统钥匙串）
    ↓
模型列表自动拉取
    ↓
健康检查 + 延迟测量
    ↓
一键启用/禁用路由
    ↓
Codex 自动重启应用变更
```

支持的协议：OpenAI 兼容 / Anthropic 等。内置热门 Provider 预设，一键导入只需填 API Key。

## 开源模块（仓库中包含）

以下模块完整开源：

- **MCP 服务器管理** — 添加、编辑、启用/禁用
- **技能包生命周期** — 导入、移除、备份、恢复
- **自定义指令** — 模板库 + diff 预览 + 历史追踪
- **系统维护** — 注册表重建、清理、诊断、守护进程管理
- **设置** — 主题、语言、刷新频率、代理、更新管理
- **自动更新** — OTA + Ed25519 签名校验
- **40+ UI 组件** — 基于 shadcn/ui 的完整设计系统

> ⚠️ 账号管理、线程管理、智能路由是**私有模块**，未包含在此开源发布中。

| 系统 | 多账号 | 会话树 | 模型注入 | 开源模块 |
|------|--------|--------|---------|---------|
