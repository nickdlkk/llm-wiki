# 判断工程不可能三角

## 三角约束

一切"判断工程"方案，最多同时满足两个，无法三者兼得：

| 属性 | 定义 |
|------|------|
| **Spec 完备性** | 所有"好"都被写下来，不留模糊地带 |
| **Goodhart 抗性** | 写下来的标准不会被优化得面目全非 |
| **Tacit 保全** | 无法言说的直觉、审美、禁忌不被抹除 |

## 三角顶点 = 三种失败团队

选择 ①+② → **牺牲③** → 写死一切，全员合规，员工出走，代码正确但没有温度

选择 ①+③ → **牺牲②** → KPI 堆到眼花，Eval 越做越多，分数涨，线上事故不降反升

选择 ②+③ → **牺牲①** → 拒绝写任何规则，"这种事说不清"，AI 跑不起来，被卷成人肉复读机

## 数学基础

- Goodhart 定律：凡被度量的都会被扭曲
- Arrow 不可能定理：任何把三个以上维度聚合成一个总排序的机制，都必然违反基本公平性

## 启示

"工程智慧，就是清楚自己选了哪条边，并承认另一条的代价。"

三块石碑不是在说"我们能抵达三角形的中心"（那个点不存在），而是说——**我们能让三条边同时被部分满足，贴着三角形的重心小步前进**。
