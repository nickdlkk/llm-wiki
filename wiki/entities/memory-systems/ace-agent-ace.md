# ace-agent/ace

**ace-agent/ace** 是 ACE 论文的**官方复现**（1,259 ⭐，2026-08）。定位与 [[Agentic-Context-Engine-ACE|Agentic Context Engine (ACE)]] (kayba) 平行——都是 Stanford/SambaNova 那篇 [ACE paper](https://arxiv.org/abs/2510.04618) 的实现，但：
- **ace-agent/ace** = 纯开源、社区驱动
- **kayba-ai/agentic-context-engine** = 商业包装 + 托管服务 [kayba.ai](https://kayba.ai)

## 关系

| 项目 | 性质 | 维护 | 商业化 |
|------|------|------|--------|
| **ace-agent/ace** | 论文复现 | 社区 | ❌ |
| **Agentic Context Engine (ACE)** | 商业引擎 | kayba-ai | ✅ kayba.ai |

> 选择哪个？纯研究用 ace-agent/ace；要做生产 agent 持续学习，用 kayba。
