# catsxp

> 📄 **原文**：[猫眼浏览器](https://www.catsxp.com/zh-hans/)

**猫眼浏览器**是一款以"简约安全"为目标的 Chrome 内核增强版浏览器。

## 核心定位

| 维度 | 描述 |
|------|------|
| **定位** | Chrome 内核增强浏览器，强调简约和安全 |
| **内核** | Chromium（Chrome） |
| **官网** | https://www.catsxp.com |
| **中文** | 完整中文官网和文档 |

## 与主流浏览器对比

| 浏览器 | 内核 | 定位 | 安全增强 |
|--------|------|------|---------|
| **猫眼浏览器** | Chromium | 简约安全增强 | 是 |
| Chrome | Chromium | Google 官方 | 基础 |
| Edge | Chromium | Microsoft 官方 | 基础 |
| Firefox | Gecko | 独立内核 | 基础 |

## 适用场景

- 需要比标准 Chrome 更强安全性的日常浏览
- 偏好简约界面而不需要大量扩展的中国用户
- 作为 Chrome 替代品，数据可与 Chrome 互通（Chromium 内核）

**注意**：这是桌面浏览器，不是开发者工具或 AI 相关软件。核心价值在于安全增强和简约设计，而非编程辅助。
